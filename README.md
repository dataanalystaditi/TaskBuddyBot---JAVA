# 📝 TaskBuddyBot – JAVA

**TaskBuddyBot** is a Java-based productivity assistant bot built in Eclipse IDE.  
It provides simple but useful daily features through a command-line interface and API integrations.

## 🚀 Features
- 🌦️ Live weather updates using OpenWeatherMap API  
- ⏰ Reminders & to-dos  
- 💡 Motivational quotes  
- 🕒 Local time & date display  
- 💱 (Planned) Currency conversion

## 🛠 Tech Stack
- Java (Core + OOP)  
- Eclipse IDE  
- HTTP API calls  
- JSON parsing (org.json)

## ▶️ How to Run
1. Clone the repo:
   `git clone https://github.com/dataanalystaditi/TaskBuddyBot---JAVA.git`
2. Import into Eclipse as an existing project.
3. Run `TaskBuddy.java` as a Java Application.
